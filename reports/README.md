# reports/

Relatórios finais gerados pelo agente `documenter` — auditorias de segurança, registros de
mudança e documentação de rede. Versionados (são os entregáveis).

Nomenclatura: `YYYY-MM-DD-<assunto>.md` (ver `PADRAO.md`, §2).

A saída bruta de cada execução (coletas, propostas, estado) fica em `runs/` — que é
git-ignorado e descartável. Aqui ficam só os relatórios curados.
