# Permanent rule: languages (i18n)

Read before writing any text that a person sees: console screens, API messages, CLI output, generated files.

## Rule

1. **Code is always in English**: variables, functions, file and folder names, YAML/JSON keys, API routes,
   translation keys. Comments, tests and commit messages are in English for new code.
2. **Every visible string goes through `t()`.** Never write a literal sentence in a screen, an API error or a
   CLI message.
   - Frontend: `import { t, fmtDateTime, fmtDate, fmtTime, fmtNumber } from "../ui.js"`.
   - Backend and CLIs: `from lib import i18n` and then `i18n.t("ns.key", name=value)`.
3. **Catalogs** live in `core/locales/<lang>/<namespace>.json`, one namespace per screen or module. A key is
   `<namespace>.<key>` in snake_case English, for example `hosts.delete_confirm`. Nested objects are flattened
   with dots.
   - Frontend namespaces use the page name (`hosts`, `claude`).
   - API namespaces start with `api_` (`api_hosts`) and CLI namespaces with `cli_` (`cli_session`).
   - Shared texts go in `common`, API error codes in `errors` and menus in `nav`.
4. **`en` is the source of truth.** Every key exists in `en`, and a language with `status: complete` in
   `core/locales/_languages.yaml` has the same keys. The guard tests enforce this.
5. **Placeholders** use `{name}`. The same placeholders must exist in every language.
   **Plurals** use `<key>_one` and `<key>_other`, with `t("ns.key", { count })`.
6. **Dates and numbers** never use a hard-coded locale such as `toLocaleString("pt-BR")`. Use `fmtDateTime`,
   `fmtDate`, `fmtTime` or `fmtNumber`, which follow the active language.
7. **Never call `t()` at module top level** in JS. The catalog loads after import. Keep the keys in constants
   and translate at render time.
   - Modules that the node tests load as plain source (`api.js`, `claude-errors.js`, `mentions.js`, `route.js`,
     `claude-sessions.js`) do not import anything. They use `globalThis.netopsT(key, vars)` with a fallback.
8. **The API returns a stable code.** Errors carry `{"error": "<code>", "detail": "<translated text>"}`. The
   frontend translates `errors.<code>` when the catalog has it, and otherwise shows `detail`. Tests check the
   `code`, not the sentence.
9. **What is never translated:**
   - data and content: inventory, memory, reports, audit log entries, hostnames;
   - values sent to or compared with the server;
   - the `[NetOps — ...]` markers injected into the AI context, until they become fixed identifiers (Plan B,
     phase 4).

## Language order

- **Console:** the user's choice (**Minha conta → Idioma**, stored per user) comes first. Then the instance
  language. Before login, the last language used in this browser. On the first-access screen, before a
  language is chosen, the browser language is used.
- **The instance language** is `core/config/project-config.yaml` → `instance.language`. It is chosen at first
  access and changed in **Configuração → Idioma da instalação**.
  - Installs older than i18n (no key) behave as `pt-BR`.
- **CLIs and scheduled tasks:** `NETOPS_LANG`, then the instance language.
- **The AI** always answers in the language the person writes in. Files it generates without a conversation
  (reports of scheduled tasks, inbox, memory) use the instance language.

## Local files in the instance language

`AGENTS.md` and `memory/MEMORY.md` come from `core/templates/<lang>/<NAME>.tmpl.md`. When there is no template
for the language, they come from `core/templates/<NAME>.tmpl.md`, the legacy Portuguese template.
`lib/local_files.py` regenerates them when the language is chosen, but only while they are still identical to a
template. Anything the user added is kept.

## Adding a language (e.g. Spanish)

1. Copy `core/locales/en/` to `core/locales/es/` and translate the values. Keep the keys and the placeholders.
2. Register it in `core/locales/_languages.yaml` with `status: partial`. Missing keys fall back to English.
   Change it to `complete` when the guard test passes.
3. Optional: `core/templates/es/AGENTS.tmpl.md`, `core/templates/es/MEMORY.tmpl.md`, and docs `*.es.md`.

No code changes.
